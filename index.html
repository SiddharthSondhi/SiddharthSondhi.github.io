OpenGL Graphics Pipeline Renderer

Real-time renderer in C++ and OpenGL with GLSL shaders. Features Blinn-Phong and PBR lighting, forward and deferred rendering, model loading, a scene management system, instanced rendering, directional shadow mapping, SSAO, HDR rendering and tone mapping, normal mapping, cubemap skyboxes, environment mapping, and framebuffer post-processing among other features. It is a work in progress renderer that is my attempt at trying to understand the fundamentals of real-time computer graphics and modern OpenGL. I am planning to keep working on it and expanding it with new features as I continue to learn more about real time graphics.

N-Body Galaxy Simulation

Gravitational particle simulation in C++ using Euler integration. Optimized from O(n²) brute force to O(n log n) via a Barnes-Hut octree, enabling real-time simulation of many particles. Visualized with OpenFrameworks.

AI-Assisted VR Anatomy App

A Unity based VR environment for anatomy education featuring 3D liver anatomy visualization, patient data exploration, and AI-assisted interaction. The project integrates local LLM inference, speech-to-text, text-to-speech, and a function calling system to allow an LLM to control objects, anatomical structures, and patient information within the environment based on the user's commands. Developed as part of MSCS thesis work at San Jose State University.
